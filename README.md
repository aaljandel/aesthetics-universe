# Beauté By Alai’a Aesthetics — website concept

A responsive one-page sample clinic website using plain HTML, CSS and JavaScript.

## Preview / features
- Beige, gold and ivory styling inspired by the supplied brand assets.
- Responsive sticky menu, working in-page navigation and mobile menu.
- Treatment information modal, gallery lightbox, FAQs, demo enquiry form.
- Semantic landmarks, focus styles, reduced-motion support, descriptive alt text.
- No framework / build step: Cloudflare Pages output directory is the repository root.

## Important
- This is a **sample/demo**, not a production clinic website.
- Images are illustrative external Unsplash images, not clinic photographs, treatment outcomes or endorsements. Verify licence and replace with approved brand photos prior to client handover.
- Booking and contact details have **not** been provided; no enquiries are transmitted or stored. Connect a real booking provider or compliant contact backend only after approval.
- Treatment availability, clinician qualifications, regulated medical advertising and privacy requirements must be reviewed before launching the final clinic website.
- Search indexing is disabled deliberately for this sample.
- Brand spelling is taken from the supplied artwork.

## Branch isolation
This brand's demonstration is on `beaute-by-alaia-demo` within the `aesthetics-universe` repository as a **temporary isolated branch**, to avoid overwriting other client websites. Move to a dedicated repository when available.

## Local
Open `index.html` in a browser. Images and Google fonts require an internet connection.
